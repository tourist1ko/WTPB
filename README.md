# PB Rank 1.6.0

Лимит: 10 запросов за любые последние 60 секунд для каждого пользователя. Все команды /pb, /rank и кнопки страниц используют общий счётчик. Лимит действует и на администраторов. После превышения бот отвечает только пользователю с временем ожидания. Отклонённые из-за лимита попытки не продлевают ожидание. Автоподсказки при вводе не расходуют лимит. Счётчики хранятся в памяти и сбрасываются при перезапуске.

## Что нового в 1.6.0
- Убраны команды /pb stat update, /pb stat addplayer, /pb stat removeplayer, /pb stat list и /pb import. Всё делается автоматически.
- /pb register сразу добавляет в статистику игроков из состава полка на официальном сайте и запускает загрузку боёв текущего сезона.
- Бот сам проверяет бои текущего сезона: при запуске, сразу после /pb register и затем каждые 10 минут. Плюс раз в минуту проверка новых боёв.
- /pb status показывает, что бот работает (время работы, задержка Discord), привязанный полк, сезон, число игроков и учтённых ПБ, ход загрузки.
- Исправлен поиск полка: тег сравнивается без украшений, поэтому «[105HP]» с сайта и «┾105HP┿» в архиве считаются одним полком, а чужой полк с похожим тегом не подставляется. Название полка отделяется от тега по точному полному названию.
- Исправлено, что бои не загружались: один недоступный отчёт больше не останавливает весь сезон, после частичной загрузки новые бои снова ищутся, а если официальное расписание нового сезона ещё не опубликовано, используется обычный двухмесячный сезон (помечается в /pb status).

## Команды
/pb register name:полное название полка (или тег) — привязать полк. Только администратор.
/pb unregister — отвязать полк, статистика сохраняется. Только администратор.
/pb status — работа бота и привязанный полк. Доступно всем, ответ виден только вызвавшему.
/pb br — текущий и следующий БР.
/rank — рейтинг игроков полка за текущий сезон.

## Статистика за сезон
/rank показывает текущий сезон по официальному расписанию полковых боёв (даты по Москве). У каждого сезона отдельные результаты, старые сохраняются.
Игроки состава полка добавляются при /pb register и обновляются раз в 6 часов. Игроки из отчётов боёв полка добавляются автоматически. Бывшие участники без боёв убираются из списка, с боями остаются.
Сортировка: сначала игроки с боями, затем К/Д, WinRate, ник. До 8 игроков на странице, кнопки Назад и Далее.
К/Д = (убийства танков + убийства самолётов) / смерти. WinRate = победы / (победы + поражения).

Источник боёв: публичный архив https://www.antoniocnz.com/en/wt (STATS_SOURCE=tactical, без ключа). Он может содержать не все сыгранные бои. Учитываются только полные realistic-отчёты с явным победителем. Ничьи и неполные отчёты не превращаются в поражения.
Каждый отчёт сохраняется в SQLite, повторно бои не начисляются. После перезапуска загрузка продолжается с места остановки. HTTP 429 соблюдается автоматически.
Необязательный STATS_SOURCE=wtapi требует WTAPI_KEY с SQB-доступом.

## Запуск Railway
Файлы в корень репозитория. Dockerfile включён. Variables: DISCORD_TOKEN, GUILD_ID, DATA_DIR=/data, STATS_SOURCE=tactical. Подключи прежний Volume к /data.
Одна реплика, один процесс и один SQLite. Docker исправляет права Volume без удаления базы и понижает UID/GID.
Приглашение бота: scopes bot, applications.commands. Права View Channels, Send Messages. Разрешение Attach Files для рейтинга больше не требуется. Администратор самому боту не нужен.
При запуске актуальные команды заменяют прежние команды этого приложения. После Ready при необходимости обнови Discord Ctrl+R.

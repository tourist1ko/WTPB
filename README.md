- Инструкция по деплою: RAILWAY.md.

# JASAQ v8.2 — Squad Randomizer UI

Новый интерфейс по спецификации «JASAQ Squad Randomizer — Visual Assets & UI Specification». Серверная логика и синхронизация из v8.1 сохранены.

## Что изменилось
- Dark military UI: фон `#111820`, панели `#202B35`, акцент `#C83B35`, текст `#D8DEE5`. Тонкие границы, без фоновых картинок и декоративных эффектов.
- Главная страница: справа по центру три кнопки — **Жасаққа бөлу**, **Соғыс рейтингі**, **Соғыс аймағы**. Нажатие включает/выключает этап. У первых двух справа шестерёнка: открывает боковую панель настроек справа.
- Внизу большая кнопка **АЛҒА**. Слева список участников голосового канала.
- Настройки «Жасаққа бөлу»: количество жасақов 2 / 3 / 4 (новое поле `squads` в настройках и в плане матча, сервер распределяет по кругу). Настройки «Соғыс рейтингі»: пул BR.
- Анимации:
  1. Жасаққа бөлу — карточки игроков (шаблон `card-player.svg`) вылетают из колоды (`flip-card-back.svg`) и раздаются по жасақам.
  2. Соғыс аймағы — карточка карты переворачивается (`rotateY` + `backface-visibility`), лицевая сторона — изображение режима + `card-map.svg`.
  3. Соғыс рейтингі — горизонтальный цифровой барабан (`br-roller-frame.svg`), 3.6 с с плавным замедлением.
- Все иконки — inline SVG-спрайт в `web/index.html`. Пути взяты из `JASAQ_Graphic_Assets/svg` без изменений; цвет и толщина линии вынесены в CSS (`currentColor`, `vector-effect: non-scaling-stroke`, одна толщина `--jq-stroke`). Эмодзи и символы-иконки убраны.
- Размеры масштабируются от ширины экрана (`clamp`), на узких экранах кнопки сверху, АЛҒА закреплена внизу.
- Демо-режим: тестовый состав больше не затирается пустым списком.
- `hangar.png` удалён (не используется).

# JASAQ v9.1.1

# JASAQ v9 — Showcase

Discord Activity для автоматического состава из текущего голосового канала, случайного распределения по командам, режима и BR.

## Основные изменения v9
- Полностью переработанный cinematic military/KZ UI по утверждённому референсу.
- Нет внутренней кнопки присоединения: состав берётся из voice channel автоматически.
- Первый подключившийся пользователь — лидер, остальные — зрители.
- Во время подбора управление блокируется у всех.
- Skip синхронный: нажатие любого участника завершает текущую анимацию для всех.
- Новый подбор закрывает предыдущий результат на всех клиентах.
- BR можно включать/выключать из пула.
- BR-анимация — чистая вертикальная рулетка без прицела.
- Режимы используют детализированные cinematic изображения техники вместо простых SVG.
- `/terms` и `/privacy` сохранены.

## Переменные Amvera
```
DISCORD_CLIENT_ID=...
DISCORD_CLIENT_SECRET=...
SESSION_SECRET=...
ALLOWED_GUILD_ID=...
PORT=3000
ALLOW_DEMO_FALLBACK=true
```

`ALLOW_DEMO_FALLBACK=true` рекомендуется только на этапе показа. После исправления OAuth можно выключить.
